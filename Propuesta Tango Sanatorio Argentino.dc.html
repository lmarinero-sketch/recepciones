Integración de Comprobantes en Tango Gestión

Automatización de carga masiva, prevalidación y generación de asientos contables automáticos.

Sanatorio Argentino
Inversión: $10.000.000 ARS
Duración: 90 días · 3 etapas

1. Situación Actual

El Sanatorio Argentino recibe aproximadamente 200 comprobantes mensuales de proveedores diversos en múltiples formatos: PDFs nativos (con CAE de AFIP), imágenes (tickets, facturas fotografiadas) y archivos mixtos sin estructura.

Hoy el proceso es 100% manual. Cada comprobante se tipea línea por línea en Tango, lo que genera:

✕Retrabajo contable: 15–20 horas mensuales del equipo administrativo.
✕Errores de imputación: 5–10% de comprobantes con cuentas incorrectas.
✕Demora en cierres: la contabilidad cierra 2–3 días después de recibir los comprobantes.
✕Falta de auditoría: sin trazabilidad de qué se importó ni cuándo.

2. Solución Propuesta

Proponemos una plataforma de automatización de punta a punta que captura, valida y carga los comprobantes directamente en Tango Gestión, generando los asientos contables sin intervención manual.

Componentes Principales

✓Captura automática: ARCA (facturas electrónicas) + OCR/IA (imágenes y PDFs).
✓Prevalidación inteligente: verificación de CUIT, detección de duplicados y clasificación de gastos.
✓Carga vía API REST: integración directa con Tango, sin interfaz manual.
✓Asientos contables automáticos: generación automática al ingresar cada comprobante.
✓Panel de auditoría: consulta en Tango Live con el estado de cada carga.

3. Flujo de Datos

ARCA / Imágenes  →  Extracción (IA/OCR)  →  Prevalidación (SQL)  →
API Tango  →  Módulo Compras  →  Asiento Contable Automático

Cada comprobante recorre un pipeline determinístico: se extrae, se valida contra reglas de negocio, se carga por API y se contabiliza automáticamente, quedando auditable en cada paso.

4. Impacto en Tango Gestión

API REST Funcional
Carga de comprobantes sin interfaz manual, directamente al módulo Compras.
Parametrización Contable
Proveedores, conceptos y modelos de asientos configurados en Tango.
Asientos Automáticos
Generación contable en el ingreso del comprobante, sin doble carga.

Consultas y tableros de auditoría sobre la base de datos de Tango.

Parametrización Contable (40% del esfuerzo)

La base de una automatización confiable es una configuración contable rigurosa en Tango. Este trabajo concentra el 40% del esfuerzo del proyecto y define cómo cada comprobante se traduce en un asiento correcto.

1
Proveedores: ficha contable con cuenta a pagar y centro de costo.
2
Conceptos de Gastos: Insumos Médicos, Servicios, Utilidades.
3
Tipos de Comprobantes: FAC, NC, ND.
4
Modelos de Asientos: Estándar, Con Percepción, Notas de Crédito.
5
Parámetros Contables: activar "Genera asiento en el ingreso".
